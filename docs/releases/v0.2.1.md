TypeTide-Win 0.2.1 — 独立功能配置与紧凑输入翻译。

### 本次更新

- 新增输入翻译：默认 Alt+Q 打开，Ctrl+Enter 翻译，Esc 关闭并保留本次运行的草稿；点击窗口外部不会关闭。
- 设置页改为 Features，划词翻译、润色替换、输入翻译分别配置快捷键、源语言、目标语言、Provider、风格与提示词。
- 支持自动语言规则、保持原语言润色，以及编辑提示词、恢复默认提示词。
- 快捷键直接绑定所属功能，迁移已有自定义绑定，并在功能列表显示可用／冲突状态。
- 输入翻译采用小巧的无标题栏弹窗，上下语言选择对应输入与译文；支持语言交换、复制、隐藏滚动条后的滚轮浏览。
- 统一各弹窗的 SVG 复制图标、复制成功反馈及深浅主题样式。
- Provider 选择与路由说明统一放在设置中；指定服务被删除后回退默认服务顺序。
- 托盘菜单增加输入翻译入口。

### 下载

- `TypeTide-Win-Setup-0.2.1.exe`：Windows x64 安装包。
- `TypeTide-Win-Windows-0.2.1.zip`：Windows x64 便携版。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

要求 Windows 10 或更新版本。使用远程 Provider 时，文字会发送到配置的服务；仅使用本机 Ollama 可离线运行。

本版本通过 GitHub Actions 构建，发布前运行内置自检、弹窗回归和本地 HTTP Provider 协议／回退测试。
