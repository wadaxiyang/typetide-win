TypeTide-Win 0.2.0 — Windows 原生系统级 AI 翻译与改写。

### 本次更新

- 仅保留 Windows / Win32 实现，统一使用 TypeTide-Win 名称。
- 更新地址、下载入口和安装器链接指向本项目 `wadaxiyang/typetide-win`。
- 使用透明 SVG 波浪图标及更明亮的渐变配色，修正深色设置页面的图标、文字和链接对比度。
- 翻译时显示加载提示，模型完整返回后一次展开全文，移除旧的逐字／粒子动画。
- 新增有序 Providers 列表：添加、编辑、删除，以及选中后上移／下移。
- 支持 Ollama、OpenAI-compatible、Anthropic Messages、Gemini 原生 API 格式。
- 首选服务失败后按顺序回退；失败的半截结果不会混入译文，取消请求不会继续尝试后续服务。
- 旧版单服务配置自动迁移，每个 Provider 的密钥独立保存在 Windows 凭据管理器中。
- 侧边栏整理为常规、Providers、翻译规则、快捷键与触发、排除应用、关于与诊断。

### 下载

- `TypeTide-Win-Setup-0.2.0.exe`：Windows x64 安装包。
- `TypeTide-Win-Windows-0.2.0.zip`：Windows x64 便携版。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

要求 Windows 10 或更新版本。云端 Provider 及回退服务会接收选中的文字；仅保留本机 Ollama 可在本地离线使用。

本版本通过 GitHub Actions 构建，发布前运行内置自检、弹窗回归和本地 HTTP Provider 协议／回退测试。未使用真实云端模型密钥进行联测。
