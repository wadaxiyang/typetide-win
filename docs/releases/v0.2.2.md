TypeTide-Win 0.2.2 — 修复运行中升级时无法关闭旧进程的问题。

### 本次更新

- 正确处理 Windows Restart Manager 的退出通知，安装更新时完整退出托盘程序并释放可执行文件。
- 取消退出请求时保持程序运行；关闭隐藏主窗口时不再遗留后台进程。
- 安装器兼容 0.2.1 及更早版本：正常退出等待超时后，可关闭仍占用安装目录程序文件的旧进程。首次升级旧版可能需要等待约 30 秒。
- 新增进程退出、旧版兼容及真实安装包升级测试，检查文件更新、设置保留和其他路径的程序不受影响。

### 下载

- `TypeTide-Win-Setup-0.2.2.exe`：Windows x64 安装包。
- `TypeTide-Win-Windows-0.2.2.zip`：Windows x64 便携版。
- `SHA256SUMS.txt`：SHA-256 校验值。

如果旧安装器仍停留在无法关闭应用的错误页，请取消该次安装，然后使用本版本安装包重新升级。升级保留已保存设置；请先保存仍在输入窗口中的临时草稿。
